What it does

One idea, done carefully.

Add to Vault. Everything else exists to make that safe: strong encryption, a recovery key, verified backups and a lock screen that gives nothing away.

  • Add to Vault

    Pick files or folders and they go into an encrypted vault. Open, preview or restore them whenever you unlock.

  • Boring cryptography

    XChaCha20-Poly1305 encrypts your files. Argon2id turns your password into a key. Built on libsodium.

    • XChaCha20-Poly1305
    • Argon2id
    • libsodium

  • Local-first

    Your vault is a folder on your PC, or a drive you choose. No account to create and no cloud sync to trust.

  • A recovery key you can actually keep

    Forget your password and the recovery key still opens your vault. Save it to a file, keep it offline. Regenerate it and the old one stops working at once.

  • Backups that verify

    Back up vault copies the encrypted folder to a drive you pick, then checks every file against the original.

  • Locks behind you

    Auto-lock when you step away. Anything you copy is cleared after 30 seconds and kept out of Windows clipboard history.

  • A quiet lock screen

    Locked means locked. The lock screen does not show where your vault lives or what is inside it.

Setup

Four steps, then it is yours.

  1. 01

    Location

    Choose where the vault folder lives. Uninstalling Deadlock never deletes it.

  2. 02

    Password

    Set a master password. Only you know it, and it is never stored in plain form.

  3. 03

    Recovery key

    Save the key to a USB drive or write it down. Keep it away from this PC.

  4. 04

    Confirm

    Type two groups of the key to prove you saved it. Only then is the vault created.

Nothing is written to disk until you finish. Close the window halfway and setup simply starts again.

Before you trust it

Honest limits of version 0.1.

  • Windows only

    Deadlock runs on Windows 10 and 11. There is no macOS, Linux or phone version.

  • Not independently audited

    It is built on well-known libraries, but there has been no outside security review yet.

  • Unsigned installer

    Windows SmartScreen may warn you until the app has a code-signing certificate.

  • No sync between devices

    Your vault stays on the PC or drive you chose. Back it up yourself.

  • Deleted folder means deleted files

    The recovery key restores access, not a vault folder you removed. Keep a backup.

  • No password and no recovery key means no way in

    Nobody, including the author, can recover your files.

FAQ

Questions, answered plainly.

Is Deadlock really free?

Yes. There is no paid tier and no account. The source code is on GitHub.

Windows says “protected your PC”. Is that a problem?

The installer is downloaded directly from this site and is not code-signed yet, and SmartScreen warns about apps it does not know. Choose More info, then Run anyway. If you are unsure, build it from the source yourself.

What if I forget my password?

Use your recovery key on the lock screen. It opens the vault without the password, and you can set a new password afterwards. Without either, the files cannot be recovered.

What if the vault folder gets deleted or moved?

If it was moved, point Deadlock at the new place. If it was deleted, restore it from a backup. The app never creates a fresh empty vault by itself, and the recovery key cannot bring back deleted files, so keep backups on another drive.

Does it upload my files anywhere?

No. Deadlock has no accounts and no cloud sync. Your vault stays in the folder you chose. You can read the code on GitHub to check.
